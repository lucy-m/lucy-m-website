# Lucy Mair's Special Place

This is the code for the best website on the planet, https://lucym.dev/.

Built with Fable and Svelte.

## Running locally

1. Install `node` v23.8 and `dotnet` CLI with SDK version 9.0.200.
2. In `svelte` run `npm install`.
3. In `svelte/fable` run `dotnet tool restore`.
4. In `svelte` run `npm run start` and `npm run start:fable` in separate terminals.
